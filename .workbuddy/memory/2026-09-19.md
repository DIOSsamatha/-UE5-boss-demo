## 2026-09-19 16:03：普攻手感优化（移动中自然 / 连段加速 / 不拉回）
- 新增 4 个可调 UPROPERTY（在 `UGA_PlayerNormalAttack`）：
  - `AttackMoveSpeedScale`（默认 0.f）：攻击时把 `MaxWalkSpeed` 压到 `原速×该值`。0=原地扎根，
    解决“边走边砍时上半身挥砍、下半身滑步（月球漫步）”的不自然感；根骨位移本就关 → 位移不拉回。
    想要边走边砍可设 0.2~0.4。ActivateAbility 存档 `SavedMaxWalkSpeed`，EndAbility 恢复。
  - `ComboSpeedupPerStage`（默认 0.12f）：连段加速，第 N 段播放速率 = `1 + 0.12×ComboIndex`，
    越往后越快 → 连续点击时连段更紧凑流畅。
  - `ComboWindowOpenRatio`（默认 0.20f）：连段窗口提前开放比例（相对本段有效时长），越小越跟手。
- 关键修正：连段加速后实际在屏时长 = `Len/PlayRate`，**窗口计时必须用有效时长 `EffectiveLen`**，
  否则窗口会落在动画放完之后（之前用原始 Len 在加速后会偏后）。命中窗 0.18/0.78、连段窗开=0.20×Eff、
  关=min(开+ComboResetDelay, 0.95×Eff) 钳制在本段内防跨段串扰。
- 新增输入缓冲 `bBufferedNext`：窗口未开时点的左键先缓冲，`OnComboWindowOpen` 一开立即续段，不丢输入。
