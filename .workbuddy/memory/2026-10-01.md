## BOSS 移动动画：方向化 Jog（修掉"溜冰/倒滑/月亮步"）
- 症状：BOSS 绕圈走位 / 后撤时只播 `Jog_Fwd`，画面"腿往前跑、人往旁边/往后溜"= 月亮步。无头实跑 `[Boss][anim自检]` 证实动画本身在播、骨头在动，只是方向永远前冲。
- 根因：`UpdateBossLocomotion` 只用 `BossJogAnimation`(Jog_Fwd)，没按移动方向选序列。
- 修复（`Boss/BossCharacterBase.{h,cpp}`，已 `run_build.py` 构建通过 + 无头复测确认）：
  - 新增 `BossJogBwdAnimation / BossJogLeftAnimation / BossJogRightAnimation`（Khaimera 自带 `Jog_Bwd/Left/Right`，SetupBossAnimation 里加载，加法/缺失则留空）。
  - 新增 `PickLocoJogSequence()`：把水平速度转到自身局部空间，按 前(X)/右(Y) 主导分量选 Fwd/Bwd/Left/Right，任一缺失回退 Fwd。
  - 新增 `ComputeLocoPlayRate()`：实际速度 / `BossJogReferenceSpeed`(默认380) = 播放倍速（夹 0.5~1.8），消脚速≠移速的打滑。
  - `bBossLocoPlayingJog` 语义改为 `Desired != BossIdleAnimation`（任一 Jog 都算 moving）；hysteresis/dwell 逻辑保持不变。
- 复测：日志已出现 `Jog_Left/Right/Bwd/Fwd` 混合切换，方向正确。

## BOSS 移动再修：模型不动整体滑动 + 类滑步（2026-10-01 第二轮）
- 用户复测仍报：①"模型不动整体滑动，但有时又会有移动动作动画"②"移动像滑步"。
- 查根因（无头抓 `[Boss][动画] 切换位移动画` 日志 + Python 查素材属性）：
  - 素材：`Jog_Fwd/Bwd/Left/Right` 全部 `enable_root_motion=False` + 非加法 = **纯原地(In-Place)动画**。故"滑步"不是根位移被丢，而是原地腿循环 vs 胶囊速度没对齐（速率匹配问题）。
  - 真凶：`GetVelocity()` 在 AI 直驱下**逐帧 0↔380 抖动**。旧 `UpdateBossLocomotion` 用原始速度做 Idle/Jog 判定 → 读到 0 退 Idle（腿冻住），下一帧 380 又播 Jog；而胶囊一直被推着走 → "模型不动整体滑动、有时又动"。方向每帧翻转还会 `PlayAnimation` 清零进度→卡第 0 帧像滑步。
- 修复（`Boss/BossCharacterBase.{h,cpp}`，已 `run_build.py` 构建通过 + 无头复测确认）：
  - 新增 `SmoothedLocoSpeed` 低通滤波（FInterpTo, rate 6）：判定/倍速都用平滑速度，吸收逐帧抖动；持续移动时不再掉回 Idle，只有真停下才衰减进 Idle。
  - 新增 `LocoDirSwitchTimer` + `LocoDirSwitchCooldown`(默认0.22s)：方向化 Jog 限频切换，绕圈时沿用当前方向资产、不再每帧重置动画。
  - `ComputeLocoPlayRate` 改用平滑速度（倍速平滑、不随原始速度忽快忽慢）。
  - 日志加"原始速度/平滑速度"两列便于复验。
- 复测铁证：`原始速度=0 平滑速度=281 → 行走 Jog(Fwd)`、`原始速度=0 平滑速度=105 → 行走 Jog(Fwd)`（不再掉 Idle）；仅 `平滑速度=4/1/6/3 → 待机`（真停才 Idle）。
- 残余脚底打滑说明：`BossJogReferenceSpeed=380` 已等于 BOSS `MaxWalkSpeed`，常速奔跑倍速=1.0 为最合理默认；若实机仍觉得滑，调 `BossJogReferenceSpeed`（试着往 500~650 调，越接近动画设计步速越不滑）。
- 注：无头 `-NullRHI` 下 `ShouldTickPose=0 / 骨头移动=0` 是空渲染管线假象，PIE 正常（用户已确认能看到动画），勿据此判断。
