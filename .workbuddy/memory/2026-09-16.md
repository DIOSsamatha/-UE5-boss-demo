## 移动动画接线（ABP_FightPlayer + BS_FightPlayer）
- WalkSpeed=400, RunSpeed=700（FightPlayerCharacter.h）。目标：BS 横轴 Speed 范围 0~700 对应 Idle@0 / Walk_F@400 / Run_F@700。
- SwordAnimsetPro 的 Walk/Run 是 Root-Motion 动画；ABP 的 RootMotionMode 默认 `RootMotionFromMontagesOnly`（非 montage 动画的 root motion 被丢弃）→ 原地播放、不叠加位移。**别设成 `NoRootMotionExtraction`**（会前后抖）。
- **⚠️ 更正**：本文件早先记的"BS 横轴已叫 Speed / AnimGraph 已用 BS + BlendPosesByBool"是**计划值，实际资产不是这样**。实测见下方「资产实测」一节。
- **坑**：AnimBP 里 TryGetPawnOwner 返回 APawn*，而 GetCharacterMovement/IsFalling 属于 ACharacter / UCharacterMovementComponent，APawn 上搜不到 → 必须中间插 `Cast To Character`。BP 节点名带空格（"Get Velocity" 而非 GetVelocity）。
- **关键修正**：`Velocity` 在引擎里只是 `UPROPERTY(Replicated)`、**无 BlueprintReadOnly**，蓝图里从 Get Character Movement 的脚拉不出 Velocity 属性！正确做法是用 Character/Pawn 上的 `Get Velocity()` 函数（BlueprintCallable）——从 Cast 后的 Character 脚直接拉 `Get Velocity` → VectorLength → Speed。可省掉 Get Character Movement 这步。
- **locomotion 动画位置（实测）**：**Idle 只在 `In-Place/Idle_Anim`**；**`Walk_F/B/L/R` 和 `Run_F/B/L/R` 只在 `Root-Motion/`**（In-Place 目录下没有任何 Walk/Run）；`In-Place/Jump_Loop_Anim` 存在。
- ABP 变量名 Speed / IsInAir 必须与 BS 轴名完全一致（区分大小写）。
- 正确 EventGraph 链路（**实测玩家已接对**）：`Event Blueprint Update Animation` →(exec)→ `Cast To BP_FightPlayer`（对象脚接 Try Get Pawn Owner）→(exec)→ `Set Speed` / `Set IsInAir`；数据链：Try Get Pawn Owner → Cast → `Get Velocity` → `VSize` → Set Speed 的 value 脚；同一 Cast 脚再拉 `Is Falling` → Set IsInAir。
- 排错顺序：①检查 Mesh 的 Anim Class = ABP_FightPlayer；②ABP 里把 BS 的 Speed 脚临时接常量 400，若变走路则问题在 Speed 变量（EventGraph），若不变量在 BS 采样点；③用 AnimBP Debugger / 变量右键 Watch 看 Speed 实时值。

## 重大更正：要"前后左右全有"必须横移(strafe)，不是转向移动方向
- **用户需求升级**：不要只前后+跳跃，要 WASD 前后左右 + 4 斜向 都有动画。
- **根因**：之前 `FightPlayerCharacter` 构造里 `bOrientRotationToMovement = true`，角色永远转向移动方向 → 按 D 身体先转过去朝前 → 永远只播前行动画。这是"只有前后"的元凶。
- **修复（已写进 cpp）**：
  ```cpp
  bUseControllerRotationYaw = false;
  bUseControllerDesiredRotation = true;            // 身体平滑转向控制器朝向(镜头/锁定)
  MoveComp->bOrientRotationToMovement = false;     // 关键：关掉转向移动方向，才能横移出左右/后退
  MoveComp->RotationRate = FRotator(0.f, 720.f, 0.f);
  ```
  改完必须**关编辑器重编** `demoEditor` 才生效。移动仍按控制器朝向计算，所以"移动跟随镜头"不变，只是身体不再追着移动方向转。
- **BS 改 2D 横移网格（Forward × Right 轴，已确认轴名就是 Forward/Right）**：
  - 轴范围都设 -700~700；Walk 环半径=WalkSpeed(400)，Run 环半径=RunSpeed(700)，斜向=半径/√2。
  - 采样表：Idle@(0,0)；Walk_F/B/L/R@(±400,0)/(0,±400)；Walk_四斜@(±283,±283)；Run 同理@(±700,0)/(0,±700)/(±495,±495)。共 17 点。
- **ABP EventGraph 用点乘算双轴**（不是单 Speed）：`ForwardSpeed = dot(Velocity, ActorForwardVector)`，`RightSpeed = dot(Velocity, ActorRightVector)`；两个新变量 `ForwardSpeed`/`RightSpeed`。
- **ABP AnimGraph**：删掉空 StateMachine（没 transition 的元凶），用 BlendSpacePlayer（已有节点）指向 BS_FightPlayer，Forward 脚←ForwardSpeed、Right 脚←RightSpeed，→ Output Pose（可加 BlendPosesByBool(IsInAir) 接 Jump_Loop）。
- `Docs/MovementAnimationGuide.md` 已重写为 8 向横移完整清单（资产清单/坐标表/EventGraph 点乘连线/AnimGraph/排错表）。
- **关键认知**：角色用 `bOrientRotationToMovement=true` 的 demo 只需要 1D 速度混合（身体总朝前）；要做 4/8 向 strafe 动画，**必须**关掉它并改用 Forward×Right 2D 混合。这两个方案互斥，下次别混。
